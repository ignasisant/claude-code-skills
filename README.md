# Claude Code Skills (free)

14 free, practical skills for Claude Code, installable as one plugin.

## Install
```
/plugin marketplace add ignasisant/claude-code-skills
/plugin install claude-code-skills@ignasisant-skills
```

## Skills
| Skill | What it does |
|---|---|
| `artifact-prototype` | Idea → prototype artifact → design review → implement in your repo → verify |
| `artifact-design-review` | Scores a prototype on usability and WCAG AA, lists exact fixes, applies them |
| `prototype-handoff-spec` | Turns an approved design into a build plan mapped to your codebase |
| `visual-match-verify` | Screenshots + pixel diff of the build vs the approved design |
| `claude-hooks-builder` | Designs, writes and tests Claude Code hooks |
| `claude-plugin-packager` | Packages skills, commands, agents and hooks into a plugin |
| `subagent-designer` | Focused subagents with least-privilege tools and clear triggers |
| `claude-in-ci` | Claude Code in GitHub Actions for PR review and fixes, with guardrails |
| `prompt-eval-harness` | Eval suite for prompts, skills and agents |
| `agent-sdk-starter` | Scaffold an agent on the Claude Agent SDK (Python or TS) |
| `tool-schema-designer` | Tool definitions Claude calls correctly |
| `session-handoff` | Save state to HANDOFF.md and resume cleanly in a new session |
| `artifact-dashboard-from-data` | CSV/SQL/API → shareable dashboard artifact |
| `claude-permissions-hardening` | Audit and harden Claude Code permission settings |
